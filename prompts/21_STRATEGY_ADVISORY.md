# 21 — Strategy & Advisory (Secondary Workflow)

Use secondarily when a primary-route deliverable requires choosing direction,
comparing options, advising a person/team, or developing an implementation strategy.

1. State the decision, decision-maker, time horizon, objectives, and constraints.
2. Distinguish evidence, assumptions, preferences, and uncertainty.
3. Compare status quo and credible alternatives using explicit criteria.
4. Identify dependencies, incentives, risks, reversibility, and second-order effects.
5. Recommend a direction with triggers for review or course correction.
6. Do not treat a persuasive deck or analysis as stakeholder acceptance.

This is not a standalone default route: pair it with the primary deliverable,
such as policy, research, analytics, presentation, education, or operations.
