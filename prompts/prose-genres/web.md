# Prose Genre Overlay — Website Copy

ใช้ร่วมกับ `prompts/24_PROSE_STYLE.md` เสมอ
Checker profile: `python3 scripts/check_prose_style.py FILE --profile web`
(อนุญาตคำถามในหัวข้อ FAQ และ label แบบ "ราคา: ฟรี")

ผู้อ่านเว็บสแกนหาสิ่งที่ต้องการ แล้วตัดสินใจว่าจะทำอะไรต่อ ข้อความจึงต้องตอบว่า
"นี่คืออะไร เกี่ยวกับฉันไหม ทำอะไรต่อ" ภายในไม่กี่วินาที งานโค้ดของเว็บใช้ method `web`
(`prompts/14_WEB_DEVELOPMENT.md`) ส่วนนี้ดูแลเฉพาะถ้อยคำ

## 1. ก่อนเขียน

1. แต่ละหน้ามีผู้อ่านหลักหนึ่งกลุ่มและงานหลักหนึ่งอย่างที่ผู้อ่านมาทำ
2. เขียนสิ่งที่ผู้อ่านจะได้หรือทำได้ ไม่ใช่สิ่งที่องค์กรอยากเล่า

## 2. โครงหน้า

- หนึ่งหน้ามี H1 เดียวที่บอกเรื่องของหน้า หัวข้อย่อยอ่านเรียงกันแล้วได้ภาพรวม
- ใส่ข้อมูลสำคัญที่สุดก่อน (inverted pyramid) ย่อหน้าสั้น ใช้ list เมื่อมีสามรายการขึ้นไปที่ขนานกัน
- ปุ่มและ call to action ขึ้นต้นด้วยคำกริยา บอกผลของการกด ("ดาวน์โหลดเอกสาร" ไม่ใช่ "คลิกที่นี่")
- ข้อความลิงก์บอกปลายทางได้โดยไม่ต้องอ่านประโยครอบ ๆ

## 3. ภาษา

- ภาษาง่าย คำสั้น ศัพท์เทคนิคเท่าที่ผู้อ่านกลุ่มนั้นใช้จริง
- ใช้คำเรียกสิ่งเดียวกันให้ตรงกันทั้งเว็บ (เมนู ปุ่ม หัวข้อ เนื้อหา)
- microcopy (ข้อความ error, placeholder, ยืนยัน) บอกว่าเกิดอะไรและต้องทำอะไรต่อ

## 4. การเข้าถึงและการค้นหา

- ภาพที่มีความหมายมี alt text ที่บอกสาระของภาพ ภาพตกแต่งใช้ alt ว่าง
- หัวข้อเรียงระดับไม่ข้าม ไม่ใช้สีเป็นสัญญาณเดียว
- title และ meta description ของแต่ละหน้าไม่ซ้ำกัน บอกเรื่องของหน้าด้วยคำที่ผู้อ่านใช้ค้น
  (ประมาณ 50–60 และ 150–160 ตัวอักษรสำหรับภาษาอังกฤษ)

## 5. ตรวจก่อนส่ง

- อ่านเฉพาะ H1 หัวข้อ และปุ่ม แล้วต้องรู้ว่าหน้านี้ให้ทำอะไร
- ตรวจข้อเท็จจริงที่เปลี่ยนได้ (ราคา วันที่ ช่องทางติดต่อ) กับแหล่งข้อมูลเจ้าของ
- ดูหน้าจริงบนจอมือถือ ข้อความที่ยาวเกินจะดันเนื้อหาสำคัญลงล่าง
