# Prose Genre Overlay — Exam and Assessment Items

ใช้ร่วมกับ `prompts/24_PROSE_STYLE.md` เสมอ (กฎย่อหน้าใช้กับคำชี้แจงและเฉลยอธิบาย ไม่ใช้กับ stem)
Checker profile: `python3 scripts/check_prose_style.py FILE --profile exam`
(อนุญาตเครื่องหมายคำถามและตัวหนาสำหรับคำปฏิเสธใน stem)

ข้อสอบที่ดีวัดสิ่งที่ตั้งใจวัดเท่านั้น ข้อผิดพลาดหลักคือข้อที่ตอบได้สองคำตอบ ข้อที่เดาได้
จากรูปภาษา และข้อที่วัดความสามารถในการอ่านโจทย์แทนความรู้

## 1. ก่อนเขียนข้อ

1. ระบุ learning outcome และระดับการคิด (จำ เข้าใจ ประยุกต์ วิเคราะห์ ประเมิน สร้างสรรค์) ของแต่ละข้อ
2. ทำ blueprint: outcome × ระดับ × จำนวนข้อ × คะแนน × เวลาที่ใช้
3. ใช้ศัพท์ สัญลักษณ์ และหน่วยตามเอกสารสอนของรายวิชา

## 2. Stem

- อ่าน stem อย่างเดียวแล้วต้องรู้ว่าถามอะไร ตอบได้โดยไม่ต้องดูตัวเลือก
- ถามเรื่องเดียว ใส่ข้อมูลเท่าที่ต้องใช้ ตัดเรื่องเล่าที่ไม่เกี่ยว
- หลีกเลี่ยงคำปฏิเสธ ถ้าจำเป็นให้ทำตัวหนา (**ไม่**, **not**) และห้ามปฏิเสธซ้อน
- โจทย์คำนวณระบุหน่วย จำนวนเลขนัยสำคัญ หรือการปัดเศษที่ต้องการ

## 3. ตัวเลือก (ปรนัย)

- มีคำตอบถูกเพียงข้อเดียวที่ผู้เชี่ยวชาญเห็นตรงกัน
- ตัวลวงมาจากความเข้าใจผิดที่พบจริง หรือความผิดพลาดในการคำนวณที่พบบ่อย (ลืมแปลงหน่วย ใช้สูตรผิดกรณี)
- ตัวเลือกยาว รูปไวยากรณ์ และระดับความละเอียดใกล้กัน คำตอบถูกต้องไม่ยาวหรือเจาะจงกว่าเพื่อน
- เลี่ยง "ถูกทุกข้อ", "ไม่มีข้อใดถูก" และตัวเลือกที่ซ้อนทับกัน
- เรียงตัวเลือกตัวเลขจากน้อยไปมาก กระจายตำแหน่งคำตอบถูกให้สมดุล

## 4. อัตนัยและ rubric

- บอกขอบเขตคำตอบ ความยาว และสิ่งที่จะให้คะแนน
- rubric แยกเกณฑ์ ให้คะแนนแต่ละระดับด้วยลักษณะที่สังเกตได้ และให้คะแนนบางส่วนได้

## 5. เฉลย

- ทุกข้อมีเฉลย เหตุผลของคำตอบถูก และเหตุผลที่แต่ละตัวลวงผิด (ใช้ต่อเป็นสื่อทบทวนได้)
- แก้โจทย์คำนวณเองใหม่ทุกข้อตั้งแต่ต้น ห้ามเชื่อตัวเลขในร่าง และตรวจว่าตัวลวงไม่บังเอิญถูก
- ระบุความยากที่คาดและเวลาที่ใช้

## 6. ความปลอดภัยของข้อสอบ

- เก็บข้อสอบและเฉลยไว้ในที่ไม่เผยแพร่ ไม่ commit ลง repository สาธารณะ
- ไม่ใช้ข้อความจากข้อสอบจริงที่ยังใช้งานอยู่เป็นตัวอย่างในเอกสารอื่น
