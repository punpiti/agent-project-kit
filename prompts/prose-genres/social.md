# Prose Genre Overlay — Social Post (Facebook and similar public posts)

ใช้ร่วมกับ `prompts/24_PROSE_STYLE.md` เสมอ
Checker profile: `python3 scripts/check_prose_style.py FILE --profile social`
(อนุญาตคำถามชวนคิดและเครื่องหมายวรรคตอนที่หลวมกว่างานเขียนทางการ)

โพสต์มีผู้อ่านเปิดกว้าง ข้อความถูกตัดตอนไปแชร์ต่อได้ และผู้เขียนรับผิดชอบทางกฎหมาย
เอง overlay นี้จึงมีสองชั้น: รักษาเสียงของผู้เขียน และด่านความเสี่ยงที่ทุกโพสต์ต้องผ่าน

## 1. ระดับการแก้ (ค่าเริ่มต้น: แก้เบาที่สุดที่ได้ผล)

เมื่อผู้ใช้ส่งร่างของตัวเองมา ให้ถือว่าร่างนั้นคือเสียงที่ต้องรักษา

| ระดับ | ทำอะไร | ใช้เมื่อ |
|---|---|---|
| `L1 เกลา` (ค่าเริ่มต้น) | ตัดคำ/ประโยคซ้ำ แก้คำผิด จัดย่อหน้าและการเว้นบรรทัด | ร่างครบแล้ว |
| `L2 เรียงใหม่` | สลับลำดับการเล่าให้ประเด็นหลักขึ้นก่อน รวมประเด็นที่กระจาย | เรื่องวกวนหรือประเด็นจมกลางโพสต์ |
| `L3 เขียนใหม่` | เขียนใหม่ทั้งโพสต์จากสาระเดิม | ผู้ใช้ขอเท่านั้น |

- คงคำเฉพาะตัว สำนวน มุก อีโมจิ และจังหวะประโยคของผู้เขียน แม้จะไม่ตรงหลักภาษาทางการ
- ห้ามใส่ลีลาที่ผู้เขียนไม่ได้ใช้ เช่น hook สำเร็จรูป hashtag เป็นชุด หรือบทสรุปเชิงคำคม
- ส่งคืนเป็นร่างที่แก้แล้ว พร้อมรายการสั้น ๆ ว่าแก้อะไรและเพราะอะไร แยกจุดที่ติดด่านความเสี่ยง
- ถ้ามี voice profile ส่วนตัว (`common.md`, `social.md`) ให้ใช้ค่าในนั้นก่อนค่ากลางข้างบน

## 2. โครงที่อ่านง่ายบนหน้าฟีด

1. บรรทัดแรกบอกเรื่องหรือชวนให้อ่านต่อ ผู้อ่านส่วนใหญ่เห็นแค่ 2–3 บรรทัดก่อน "ดูเพิ่มเติม"
2. หนึ่งโพสต์หนึ่งประเด็นหลัก ถ้ามีสองเรื่องให้แนะนำแยกโพสต์
3. ย่อหน้าสั้น เว้นบรรทัดระหว่างย่อหน้า
4. ปิดด้วยสิ่งที่อยากให้ผู้อ่านได้ไป: ความรู้หนึ่งข้อ ข้อเตือนใจ หรือรอยยิ้ม

## 3. ด่านความเสี่ยง (ต้องผ่านทุกโพสต์ voice profile override ไม่ได้)

ตรวจและรายงานเป็นรายการ ไม่แก้เงียบ ๆ ถ้าข้อความเข้าข่าย ให้เสนอทางเขียนที่ยังได้สาระเดิม

1. **ไม่ชี้ตัวบุคคลในทางลบ** ทั้งชื่อ ชื่อเล่น ตำแหน่งที่มีคนเดียว รูป หรือรายละเอียดที่ทำให้
   คนรู้จักเดาได้ ให้วิจารณ์พฤติกรรม ระบบ หรือเหตุการณ์แทนตัวบุคคล
2. **แยกข้อเท็จจริงกับความเห็น** ข้อเท็จจริงต้องมีที่มาที่ตรวจได้ ความเห็นให้เขียนเป็นความเห็น
   ("ผมคิดว่า…") ห้ามเขียนข้อกล่าวหาเป็นข้อเท็จจริง
3. **ระวังข้อความที่อาจเป็นการหมิ่นประมาทหรือข้อมูลเท็จ** ข้อความที่ทำให้บุคคลหรือองค์กร
   เสียชื่อเสียงมีความเสี่ยงทางกฎหมายแม้จะเป็นความจริงบางส่วน ถ้าไม่แน่ใจ ให้บอกผู้ใช้ว่า
   จุดไหนเสี่ยงและควรปรึกษาผู้รู้กฎหมาย overlay นี้ไม่ใช่คำแนะนำทางกฎหมาย
4. **ระวังทัวร์ลง** เหมารวมกลุ่มคน (อาชีพ ศาสนา ภูมิภาค เพศ รุ่น) ประชดที่อ่านตรงตัวแล้วแรง
   หรือประโยคที่ตัดไปแชร์เดี่ยว ๆ แล้วความหมายเปลี่ยน ให้ลองอ่านแต่ละประโยคแยกจากบริบท
5. **ความเป็นส่วนตัวและลิขสิทธิ์** แชตส่วนตัว ภาพคนอื่น ข้อมูลนักศึกษา/ผู้ป่วย/ลูกค้า และรูปหรือ
   ข้อความที่ไม่ใช่ของผู้เขียน ต้องได้รับอนุญาตหรือตัดออก
6. **ข้อมูลสุขภาพ การเงิน และกฎหมาย** ที่ให้คนนำไปทำตาม ต้องมีแหล่งอ้างอิงหรือบอกขอบเขตชัด

## 4. รายงานผล

- ร่างที่แก้แล้ว (ระดับ L1/L2/L3 ที่ใช้)
- รายการแก้หลัก 3–5 ข้อ
- ผลด่านความเสี่ยง: `ผ่าน` หรือรายการจุดเสี่ยงพร้อมข้อความทางเลือก
