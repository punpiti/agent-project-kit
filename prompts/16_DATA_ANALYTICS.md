# 16 — Data Analytics

Use for data quality checks, exploratory analysis, metric diagnosis, KPI work,
statistical summaries, visualization, dashboards, and decision support.

## Route

1. State the decision/question, grain, population, time window, and metric definitions.
2. Check data provenance and quality before interpreting results.
3. Reuse validated extracts/intermediate results when their inputs and logic are unchanged.
4. Make transformations reproducible and keep raw data unchanged.
5. Distinguish descriptive evidence, statistical uncertainty, causal claims,
   and recommendations.
6. Use the smallest table/chart that answers the question; verify labels,
   denominators, units, and filters.
7. Report what was not observed or validated and what external evidence is still needed.

Load the coding prompt for SQL/Python implementation, the research prompt for
external evidence, or the presentation prompt when the deliverable is a deck.
