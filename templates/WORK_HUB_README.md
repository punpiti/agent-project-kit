# Work Hub

This folder is a small Project Radar, not a task manager or journal archive.
Keep only this README and `PORTFOLIO_COORDINATION.md` here.

The board has one short row for each active, waiting, blocked, or parked
project. Update only its last review date, one open loop, and next action when
the project materially changes.

During a weekly review, inspect rows not reviewed for 14+ days. Decide whether
each is active, blocked, intentionally parked, or forgotten. Read each
project's `.ai/PROJECT_STATE.md` only after the board identifies it as needing
attention.
