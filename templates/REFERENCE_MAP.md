# REFERENCE_MAP — <pipeline id>

A private map of an earlier project to reuse for this kind of work, so an
agent reads a few named files instead of browsing that project. Keep it
outside the shared kit: save it as `$APK_REFERENCE_DIR/<pipeline>.md` or
`~/.config/agent-project-kit/references/<pipeline>.md`, where `<pipeline>` is
the routed primary pipeline id (for example `book-writing`,
`research-activities`). `common.md` in the same folder applies to every
pipeline. The context bundle lists the maps it finds in `reference_maps`.
